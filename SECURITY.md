# Security Policy

## Supported versions

| Version | Supported |
|---|---|
| 1.0.x | ✅ |

## Reporting a vulnerability

Please **do not** open a public issue. Use GitHub's private vulnerability reporting
(*Security → Report a vulnerability*) with reproduction steps, impact and the affected version.
We aim to acknowledge reports within 72 hours and to ship fixes for critical issues within 14 days.

The platform's security design (OWASP ASVS / Top 10 mapping, threat model, production checklist) is documented in
[docs/SECURITY.md](docs/SECURITY.md).

## Acceptable use

CyberShield is a defensive tool. Only audit, scan or monitor systems and networks you own or are explicitly
authorised to assess.
