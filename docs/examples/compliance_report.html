5. Recommendations

  1. Adopt a hardened baseline (CIS Benchmark) and enforce it with configuration management.
  2. Enable a default-deny host firewall on every server.
  3. Disable direct root login, remove duplicate UID 0 accounts and require authentication for sudo.
  4. Remediate critical vulnerabilities within 72 hours and high within 7 days.
  5. Review accounts, enforce password policy and lock unused/system accounts.
  6. Apply least privilege for sudo, root access and sensitive file permissions.
  7. Filter inbound traffic with host and network firewalls; restrict exposed services.
  8. Restrict and log privileged access.
  9. Secure, manage and control networks and filter traffic.
  10. Identify vulnerabilities timely, evaluate exposure and remediate.
  11. Use only strong SSH algorithms and replace cleartext services (Telnet, FTP, HTTP) with encrypted alternatives.
  12. Configure idle session timeouts (SSH ClientAliveInterval/CountMax, shell TMOUT).
